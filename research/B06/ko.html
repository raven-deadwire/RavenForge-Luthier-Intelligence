B06 — Rethinking the Internal Signal Path

source domain · reference state · routing graph로 악기 내부 전자계를 다시 설계하는 방법

문서 목적
악기 내부 전자계를 “Pickup → Preamp → EQ → Output”이라는 하나의 직렬 chain으로 가정하지 않고, source마다 다른 electrical boundary와 player-selected state에 따라 경로가 바뀌는 routing graph로 재정의한다. ESH/Eshtronic의 현행 공식 사양과 과거에 문서화된 Direct/Studio·magnetic+piezo routing을 사례로 사용하되 세대별 회로를 동일시하지 않는다. Active magnetic, passive piezo, buffer, mixing, control placement, direct reference, split output와 switching transient를 하나의 specification language로 묶고, ASKR·EMBLA·EDDA의 내부 electronics 설계 규칙으로 연결한다.

1. 연구 질문 — 악기 내부 전자계는 왜 하나의 직렬 chain으로 충분하지 않은가

A06은 pickup-facing boundary 이후의 isolation, mixing, gain, EQ와 output을 하나의 active signal architecture로 정의했다 [1]. B06은 그 다음 질문을 다룬다. 이 stage들을 언제나 Pickup → Volume → Mix → EQ → Output 순서로 직렬 배치해야 하는가? 결론부터 말하면 아니다. source의 종류, 필요한 input boundary, 사용자가 선택한 mode와 reference state에 따라 실제 signal path는 달라질 수 있다.

특히 active magnetic pickup과 passive piezo처럼 electrical domain이 다른 source를 한 악기 안에서 다룰 때는 하나의 “preamp”라는 부품명보다 각 source가 어느 node에서 conditioning되고, 어느 node에서 합쳐지며, 어떤 control을 우회할 수 있는지가 더 중요하다. B06은 internal electronics를 parts list가 아니라 state-dependent routing graph로 기술하는 방법을 정립한다.

2. Linear Chain에서 Routing Graph로 — 부품 순서보다 node와 state를 기록한다

전통적인 schematic 설명은 stage를 왼쪽에서 오른쪽으로 나열하기 쉽다. 그러나 mode switch가 direct branch를 만들거나, piezo가 독립 buffer를 거쳐 magnetic branch와 합쳐지거나, 특정 상태에서 volume/tone이 완전히 제외되면 회로는 단일 chain이 아니라 graph가 된다.

B06 working model
Source domain → source-specific boundary → routing state → control ownership/order → merge point → reference state → output boundary

Figure 1. Linear chain과 routing graph의 차이. Direct-reference branch나 source-specific conditioning이 들어오는 순간 signal path는 단순 직렬 구조로 설명되지 않는다.

3. Source Domain — passive magnetic, active magnetic, piezo는 같은 입력 신호가 아니다

Passive magnetic pickup은 A03–A05에서 다룬 것처럼 주파수 의존 source impedance와 외부 load가 직접 결합되는 RLC source다. 반면 EMG 35DC/40DC처럼 pickup 내부에 active electronics가 있는 source는 공식 문서상 output impedance가 10 kΩ이며 9 V 전원을 소비한다 [5]. 이 경우 pickup output은 이미 능동 conditioning을 거친 source다.

Passive piezo는 또 다른 경계조건을 가진다. TI는 piezoelectric sensor를 높은 source impedance를 가진 source로 설명하며 JFET/CMOS처럼 high-input-impedance front end가 자연스러운 선택이라고 정리한다 [9]. Fishman 역시 passive piezo에서 10 MΩ impedance-matching buffer를 권장하고 1 MΩ에서는 bass response가 다소 줄 수 있다고 명시한다 [8]. 따라서 magnetic과 piezo를 물리적으로 한 악기에 넣었다는 이유만으로 동일한 input node에 바로 합치는 것은 설계 기준이 될 수 없다.

4. Reference State — “bypass”라는 한 단어를 폐기한다

Internal routing을 명확히 하려면 reference state를 세분해야 한다. Passive reference는 active stage를 실제로 우회하여 passive source가 외부 load를 다시 직접 보게 되는 상태다. Active-flat은 active path는 유지하되 EQ transfer만 nominal flat인 상태다. Direct-source reference는 pickup 자체의 active electronics는 남겨 둔 채 후단 volume/tone/EQ/routing electronics를 제외하는 상태다.

이 구분은 이후 ASKR에서 특히 중요하다. active pickup을 사용하는 악기에서 Tone Capsule을 우회했다고 해서 그 상태를 “passive”라 부르면 electrical boundary를 잘못 설명하게 된다.

5. Routing Primitive — select, condition, merge, bypass, split을 분리한다

B06은 복잡한 회로를 다섯 개의 primitive로 분해한다. Select는 source를 선택한다. Condition은 source가 보게 될 Zin, gain, bias와 Zout을 정의한다. Merge는 두 source를 합친다. Bypass는 특정 stage를 제외한다. Split은 내부에서 합치지 않고 별도 output으로 내보낸다.

같은 rotary switch라도 이 다섯 기능 중 무엇을 하는지에 따라 의미가 달라진다. “4-way mode”라는 UI 정보만으로 회로를 설명할 수 없고, 각 position이 어떤 edge를 연결하고 어떤 node를 고립시키는지 state table로 기록해야 한다.

6. ESH / Eshtronic — 현재 공식 사양과 과거 routing evidence를 분리한다

현재 Esh Stinger II 공식 사양은 4현에서 EMG 35DC 두 개, 5현에서 40DC 두 개, Volume, Tone, Pickup selector, Mode selector, active Esh-tronic special electronics와 Esh Custom piezo bridge를 명시한다 [2]. Esh 홈페이지 역시 Eshtronic과 독자적 piezo system을 브랜드의 핵심 innovation으로 소개한다 [3].

하지만 현재 공식 제품 페이지는 각 Mode Selector position의 내부 routing을 공개하지 않는다. 반면 과거 Stinger 리뷰에는 2006년 개정 Eshtronic의 4개 mode가 구체적으로 기술되어 있다 [4]. 따라서 B06은 이 routing을 historical documented implementation으로 사용하되, 현행 Stinger II가 내부적으로 완전히 동일하다고 단정하지 않는다. 세대별 회로도와 사용자 자료는 [11–12]에서 추가로 확인되지만 제조사 회로 문서와 같은 증거 수준으로 취급하지 않는다.

7. Historical Eshtronic State Map — Mode Selector가 실제 signal graph를 바꾼 사례

문서화된 과거 Eshtronic에서는 Position 1이 Direct/Studio로 선택된 active EMG pickup을 volume, tone 및 별도 preamp/control path 없이 output으로 보냈다. Position 2는 선택 magnetic pickup에 Volume/Tone을 적용했고, Position 3은 magnetic과 bridge piezo를 함께 사용하며 Volume/Tone을 거쳤다. Position 4는 piezo만 Volume/Tone을 통해 출력했다 [4].

Figure 2. 과거 리뷰에 기록된 Eshtronic routing 개념도. 현재 제품의 동일성을 주장하는 도면이 아니라, 한 개의 Mode Selector가 signal graph 자체를 재구성한 역사적 사례다.

이 사례가 중요한 이유는 “active/passive switch”가 아니라 reference path, controlled magnetic path, merged path, piezo-only path를 하나의 state machine으로 묶었다는 점이다. RavenForge가 참고할 것은 특정 4-position 배선을 복제하는 것이 아니라, source와 control의 ownership을 mode별로 명시하는 설계 방식이다.

8. Studio/Direct는 Passive가 아니다 — active pickup의 source electronics는 남아 있다

과거 Eshtronic의 Direct/Studio state를 “passive”라고 부르는 것은 부정확하다. 해당 리뷰는 active EMG를 source로 명시하며 [4], EMG의 35DC/40DC 공식 문서는 pickup 자체가 전원을 쓰고 10 kΩ output impedance를 갖는다고 공개한다 [5]. 후단 control board를 우회해도 pickup 내부 preamp는 그대로 동작한다.

Terminology rule
Active pickup → controls bypass → jack = Direct-source reference. “Passive mode”라는 표현은 pickup 자체와 후단 active stage가 모두 passive boundary로 되돌아갈 때만 사용한다.

이 구분은 tone의 우열을 말하기 위한 것이 아니다. 어떤 electrical boundary를 comparison baseline으로 삼았는지를 재현 가능하게 기록하기 위한 것이다.

9. Piezo Boundary — 높은 input impedance가 왜 branch 설계의 출발점인가

단순화한 voltage-source model에서 piezo의 series capacitance를 Cp, 다음 stage input resistance를 Rin이라 두면 저역 경계는 대략 fc ≈ 1/(2π·Rin·Cp) 형태로 이동한다. 이것은 실제 piezo의 모든 loss와 mechanical resonance를 설명하는 완전한 모델은 아니지만, Rin이 낮아질수록 low-frequency loading이 커지는 방향을 명확하게 보여준다 [8–9].

Illustrative CpRin = 1 MΩRin = 10 MΩ주의
5 nF약 31.8 Hz약 3.18 Hz예시값이며 Esh bridge 실측값이 아님
10 nF약 15.9 Hz약 1.59 Hz실제 bridge/preamplifier network는 더 복잡함

따라서 piezo branch의 첫 specification은 “piezo를 쓴다”가 아니라 sensor capacitance/출력 구조, pickup-facing Zin, buffer placement, gain과 output impedance가 되어야 한다.

10. Mixing — blend는 노브가 아니라 source isolation과 summing의 문제다

서로 다른 source를 한 node에 연결하면 각 source의 output impedance와 control network가 상대 source를 load할 수 있다. 이 때문에 “50:50 blend”라는 knob position만으로 실제 electrical mix를 정의할 수 없다. EMG B125는 두 input에 buffer를 두어 passive/passive, active/active, active/passive source를 혼합할 수 있다고 공식 설명한다 [6]. 이것은 mix 이전의 isolation이 architecture를 바꾸는 명확한 사례다.

RavenForge에서 magnetic + piezo mix를 설계할 때는 source-specific conditioning → defined gain → summing 순서를 기본 검토안으로 삼는다. Piezo가 반드시 active summing이어야 한다는 절대 규칙은 아니지만, 서로 다른 source domain을 무정의 상태로 passive-parallel 연결하는 것은 피한다.

11. Control Placement — 같은 Volume/Tone도 어느 node에 있느냐에 따라 다른 회로다

Volume/Tone은 UI 이름이 같아도 source 앞·뒤, mix 전·후, buffer 전·후에 따라 loading과 control interaction이 달라진다. EMG B125는 low-Z output 뒤에 기존 250/500 kΩ control보다 25 kΩ control을 사용하도록 명시한다 [6]. BQS-HZ 문서도 ABC, EQ, Master Volume의 wiring order를 제시하면서 master volume과 EQ의 순서를 바꿀 수 있다고 설명한다 [7].

따라서 B06에서는 control을 ownership과 position으로 기록한다. 예를 들어 “Tone”이 magnetic branch만 제어하는지, piezo도 포함한 merged bus를 제어하는지, direct reference에서는 제외되는지를 state별로 명시한다. 이것이 knob label보다 중요하다.

12. Split Output — 내부 mix와 별도 source 출력은 서로 다른 design objective다

일부 과거 Stinger II에 normal output과 direct piezo output이 별도로 존재했다는 사용자 기록이 있다 [11]. 이는 현재 전 제품의 공식 사양으로 일반화할 수 없지만, split-output architecture가 실제 연주/레코딩 workflow에서 어떤 의미를 갖는지 보여주는 사례다.

Split output은 FOH나 recording에서 magnetic과 piezo를 외부에서 독립 processing할 수 있게 하지만 jack 수, switching, grounding, user error와 stage setup 복잡도를 늘린다. 반대로 internal merge는 사용자 조작이 단순해지는 대신 외부에서 source별 processing freedom을 잃는다. RavenForge에서는 “더 많은 output이 더 고급”이라는 기준을 버리고 사용 시나리오를 먼저 정의한다.

13. Switching Transient와 State Transition — mode 수가 늘수록 전환 자체를 설계해야 한다

Routing state가 서로 다른 bias point나 charged capacitance를 연결하면 switching 순간 transient가 발생할 수 있다. Analog Devices는 audio switch에서 click/pop을 줄이기 위해 break-before-make와 shunt discharge 같은 구조를 사용하는 사례를 설명한다 [10]. 악기 내부 mechanical rotary switch가 동일한 솔루션을 써야 한다는 뜻은 아니지만, “신호가 연결되기만 하면 된다”는 접근이 충분하지 않음을 보여준다.

RavenForge validation에서는 mode별 steady-state frequency response뿐 아니라 전환 시 pop/click, level jump, mute interval, battery on/off state를 별도 항목으로 둔다. 실제 transient 크기는 prototype measurement로 남긴다.

14. Serviceability — 복잡한 routing은 기능 수가 아니라 진단 가능성으로 평가한다

Mode selector 하나에 많은 기능을 압축하면 외형은 단순해질 수 있지만 내부 fault isolation은 어려워진다. pickup source, piezo buffer, mode switch, volume/tone, merge node, output driver 중 어디에서 문제가 생겼는지 분리할 test node와 state table이 없으면 serviceability가 급격히 떨어진다.

B06은 각 state에 대해 selected source → active stage → controls → output을 한 줄로 기록하고, 전원 상실 시 어떤 branch가 살아남는지도 기록한다. 사용자에게도 mode naming을 직관적으로 제공해야 하며, 제작자는 cavity 안에서 각 branch를 probe할 수 있어야 한다.

17. ASKR · EMBLA · EDDA 적용 — 같은 “active electronics”라도 routing 목표가 다르다

ASKR

ASKR의 EMG 45TW 계열처럼 source 자체가 active인 구조에서는 Tone Capsule bypass를 true passive로 부르지 않는다. 가장 유용한 reference는 selected active pickup(s) → direct-source output과 selected pickup(s) → Tone Capsule → output의 A/B state다. TW의 coil-mode switching과 EQ bypass는 서로 다른 state dimension으로 문서화해야 한다.

EMBLA

EMBLA가 passive pickup source와 ZUTA Bass Core를 조합하는 경우, pickup interaction을 preamp 앞에서 남길지 pickup별 buffer 이후에 blend할지부터 결정해야 한다. 3-pickup option을 열어 둘 경우에는 “preamp 호환”보다 branch count, selector logic, gain matching과 serviceability가 먼저다.

EDDA

EDDA의 2 Volume / 2 Filter 개념은 B06의 source-specific parallel architecture와 직접 연결된다. 각 pickup의 filter를 summing 이전에 독립 branch로 둘 경우 global EQ와 다른 interaction이 생긴다. Alembic/Wal의 외형적 control count를 복제하는 것이 아니라 per-source processing before merge라는 원리를 명시적으로 설계하고 검증한다.

19. 연구 경계와 다음 회차 — topology를 확정하고 headroom 측정은 넘긴다

B06은 internal routing의 topology, source boundary, reference state와 state documentation까지 다룬다. 각 branch의 maximum signal swing이나 clipping margin은 A07 — 9 V vs. 18 V: Headroom and Dynamic Range에서 공급전압, bias, rail margin, gain, load와 함께 분리해 다룬다.

C03에서는 preamp/filter frequency-response mapping, C04에서는 9/18 V headroom, THD+N과 clipping threshold를 실제 prototype에서 측정한다. B06에서 제안한 mode transition의 click/pop과 state별 level difference도 measurement protocol에 포함시키되, 아직 effect size를 주장하지 않는다.

20. Source Status / Interpretation Boundary

현행 ESH 제품 구조는 제조사 공식 page를 우선한다 [2–3]. Mode Selector의 정확한 state map은 현재 공식 page에서 공개되지 않았으므로 과거 리뷰 [4]를 역사적 사례로 사용한다. Bassic/TalkBass [11–12]의 회로·사용 경험은 세대 차이를 추적하는 데 유용하지만 1차 manufacturer specification이 아니며 증거 수준을 낮게 둔다.

또한 piezo의 실제 capacitance, Esh Custom bridge의 내부 buffer topology, 현행 Eshtronic의 gain distribution과 switch contact scheme은 공개 근거 없이 추정하지 않는다. RavenForge model application은 설계 제안이며 실제 회로도와 prototype measurement로 후속 검증해야 한다.

21. 현재 결론 — Internal electronics는 “회로 한 줄”이 아니라 명시적인 state machine이다

Current conclusion
An instrument’s internal signal path should be specified as a state-dependent graph in which each source has an explicit electrical boundary, each control has a defined ownership and position, and every bypass/direct/merge state has a reproducible reference meaning.

ESH에서 RavenForge가 가져올 가치가 있는 것은 특정 4-way rotary 배선을 복제하는 것이 아니다. 중요한 것은 source별 경계를 나누고, 필요하면 direct reference를 만들며, piezo와 magnetic을 선택적으로 합치거나 분리하는 routing architecture의 사고방식이다. 반대로 mode가 많아질수록 user state visibility, transition noise, level consistency와 serviceability를 specification으로 끌어와야 한다. B06 이후 RavenForge의 electronics 문서는 “무슨 부품을 넣었는가”보다 “어떤 state에서 신호가 어디를 통과하는가”를 먼저 기록한다.
