A04 — Electrical Loading of Passive Pickups

From pickup Z(f) to the instrument output — how resistive/capacitive loading and control topology shape the loaded response

Document purpose

Extend the passive-pickup source + Zpu(f) model established in A03 to real instrument boundary conditions. Volume/tone controls, cable capacitance, and downstream input resistance/capacitance are treated as one loaded system. Conventional values such as 250 kΩ / 500 kΩ / 1 MΩ are reframed as measurable damping and resonance conditions rather than fixed tone recipes. A04 ends at passive loading; active-buffer isolation is deferred to A05.

1. Research question — why does the same pickup not have one fixed “tone”?

A03 described a passive magnetic pickup not as an ideal tone source, but as an induced source combined with a frequency-dependent terminal impedance Zpu(f). In a real instrument, however, the pickup output node is simultaneously connected to the volume pot, tone branch, cable, and the input of the next device. The in-use frequency response is therefore a property of the pickup plus its electrical boundary conditions, not of the pickup alone.

Paiva & Penttinen’s AES 131st Convention paper measured and modeled instrument cables and reported that cable capacitance changes the frequency response of a magnetic-pickup system; among the measured cables, the largest resonant-frequency difference was 1.4 kHz. That 1.4 kHz figure is not a universal upper bound: it belongs to the cable set and pickup/load conditions used in that study [1,3].

Core view

Pot value, cable length, and “high-Z input” are boundary-condition metadata, not tone labels. RavenForge records actual R, C, wiring state, and downstream interface instead of relying on nominal categories.

2. Reference circuit — define the simplest full-volume case first

For the A04 reference case, the tone branch is omitted and the volume control is at full. The induced source Es drives the output node through the coil series impedance Zs=Rs+sLs. Pickup equivalent winding capacitance Cp and the external load shunt that node. When the external load can be simplified to Rload and Cext, use C_T=Cp+Cext and R_L=Rpot∥Rin. This capacitance sum is valid only when those capacitances are effectively connected from the same electrical node to ground.

H(s) = Vout/Es = 1 / [ 1 + (Rs + sL) (1/RL + sCT) ]

= 1 / [ 1 + Rs/RL + s(L/RL + Rs·CT) + s²L·CT ]

This is a loaded output-voltage transfer function, not the pickup’s intrinsic resonance. Once a tone network, a partial-volume wiper, or multiple pickups are introduced, the system should not be collapsed into one scalar R_L/C_T unless the topology genuinely permits it; use nodal analysis or circuit simulation instead.

Mathematical caution

For this simple second-order model, if a resonant transfer peak exists, ωpeak²=[2a0a2−a1²]/(2a2²), with a0=1+Rs/RL, a1=L/RL+RsCT, and a2=LCT. Load resistance can therefore affect peak position as well as peak height/Q. The familiar 1/(2π√(LCT)) is a high-Rload, low-loss approximation.

3. Resistive loading — 250 kΩ / 500 kΩ / 1 MΩ are damping conditions

Even at full volume, the pot’s end-to-end resistance remains a resistive load from the pickup node to ground and combines in parallel with the downstream input resistance. For the same pickup and capacitance, a larger R_L generally reduces damping and preserves a higher resonant peak. But “500 kΩ is always brighter” is incomplete: peak position, peak height, and perception also depend on pickup R/L/C, cable/input capacitance, tone network, and volume state.

Nominal pot value may also differ substantially from the measured value. For example, Bourns specifies ±10% standard resistance tolerance for its Model 82 guitar pot and ±20% for Model 95 [6,7]. For repeatable prototype work, the log should therefore record measured end-to-end resistance and taper/position rather than only “500 kΩ.”

4. Capacitive loading — manage cable by total capacitance, not length alone

An instrument cable is a distributed structure, but at typical instrument-cable lengths and audio frequencies its electrical length is very small, so a lumped shunt-capacitance approximation is practical. For the same construction, total capacitance scales approximately with capacitance per unit length times length, while connectors, patches, and device input capacitance add to the assembled path. Measured total pF is therefore a more direct loading descriptor than “3 m cable.”

Paiva & Penttinen found that, under their measurement and simulation conditions, cable capacitance dominated the audible-band loading effect while cable inductance and series/parallel resistance were negligible [1]. This does not mean low-capacitance cable is universally superior. Lower capacitance tends to move the loaded resonance upward for a given pickup, making it a voicing choice rather than a quality score. As one official example, Canare specifies 160 pF/m nominal capacitance for GS-6 [8].

5. Input impedance — 1 MΩ is not “unloaded”

Amp, pedal, DI, and interface inputs have finite resistance and parasitic/input capacitance. Input resistance loads the pickup node resistively, while input capacitance can add to cable capacitance at the same node. A “1 MΩ input” may be high impedance, but it is not infinity; even a no-cable bench measurement still contains probe and fixture capacitance.

RavenForge therefore uses specified high-impedance / specified-capacitance fixture rather than “unloaded.” In product comparisons, record Rin, Cin, and cable/patch configuration when possible instead of relying on an input label alone. The mechanism by which a buffer isolates downstream cable capacitance is treated formally in A05.

6. Volume control — lowering the knob changes level and topology

When a conventional passive volume pot moves away from full, input-to-wiper resistance Ra and wiper-to-ground resistance Rb appear. The downstream cable/input is connected at the wiper, so it forms a parallel or compound network with Rb, while Ra becomes a series path between pickup and output. The result is not only attenuation: wiper source impedance and cable capacitance can also reshape the frequency response.

Audio/log taper defines the resistance-versus-rotation law; it does not change the circuit topology. A treble-bleed network is a separate frequency-dependent bypass intended to compensate some state-dependent loss, not a universal restoration of the full-volume response. “Volume down = same tone, lower level” is generally false for an unbuffered high-impedance passive system.

7. Tone control — at “10,” a standard tone branch does not completely disappear

A common passive tone control is a variable resistance Rt(θ) in series with capacitor Ct to ground. The branch may be written Ztone=Rt(θ)+1/(sCt), but the complete response must be solved with the pickup, volume, cable, and input network. With a standard pot, fully open still leaves a finite Rt, so the branch remains weakly coupled. A no-load tone pot is a distinct topology designed to physically disconnect the branch at its end position.

Values such as 22 nF or 47 nF are not universal answers for particular pickup types. The same capacitor behaves differently with different pickup inductance and load resistance. “Modern” and “50s” wiring likewise differ in which volume-pot node the tone branch uses; their volume-dependent interaction should be treated as a topology question, not as evidence that one is universally better.

The Rt–Ct branch is part of the complete guitar network. A no-load pot is treated as a separate disconnect topology.

8. Multiple pickups — separate spatial mixing from electrical interaction

Selecting two passive pickups simultaneously combines the spatial sampling/phase effects discussed in A02 and also connects their source impedances and control networks. A parallel pickup combination is not merely an arithmetic sum of two voltages; in series/parallel switching and independent V/V wiring, each pickup can become part of the other pickup’s load. Each selector state should therefore be logged and measured as a separate loaded state.

10. C02 — Pickup Loading Measurement protocol

The literature and circuit results become a RavenForge specification only after effect size is measured on the actual pickup/load combination. C02 should hold pickup baseline and excitation fixed, substitute controlled Rload/Cload conditions, and compare Hloaded(f). Do not invent a universal “significant” threshold in advance; estimate repeatability and measurement uncertainty first, then compare measured effect size with the voicing target.

11. RavenForge application — derive the load from target response, not convention

EDDA’s passive baseline should not begin with a recipe such as “vintage means 250 kΩ.” Define pickup Z(f), the target loaded response, and a reference cable/input condition, then select the pot/capacitor topology. Heritage is a decision about which historical system behavior to preserve, not a requirement to copy nominal part values.

If EMBLA/ASKR place an onboard buffer or preamp after a passive pickup, the input condition seen directly by the pickup can remain A04 metadata, while buffer output impedance and downstream cable isolation belong to A05. Current powered EMG/Fishman architectures should not be directly ranked with the traditional passive-loading model used here.

12. Current conclusion — passive-pickup output is a pickup-plus-load system property

A04 rejects the use of 250 kΩ, 500 kΩ, 1 MΩ, cable length, or “high-Z” as self-contained tone adjectives. In the reference topology, resistive loading governs damping and peak height, while capacitive loading combines with inductance to move the resonance. At partial volume, with tone networks, or with multiple pickups, the topology itself changes and must be modeled or measured in its actual wiring state.

Current design position

RavenForge specification rule: pickup model + wiring state + measured pot resistance/taper position + total external capacitance + destination input condition → loaded-response target → C02 validation. Nominal component categories are implementation choices, not the target.
