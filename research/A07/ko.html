1. 연구 질문 — supply voltage는 tone인가 operating envelope인가?

A07의 핵심 질문은 “18V가 더 좋은 톤을 만드는가?”가 아니다. 정확한 질문은 “주어진 onboard preamp가 실제 사용 조건에서 요구하는 최대 신호 스윙을 9V에서 충분히 선형으로 처리하는가, 아니면 rail margin을 늘리기 위해 18V가 필요한가?”이다.

공급 전압이 두 배가 되면 이상적인 대칭 신호 스윙의 상한도 두 배가 될 수 있으므로 전압비만 놓고 보면 20·log10(18/9) = 6.02 dB다. 그러나 실제 usable headroom은 bias/reference, input common-mode range, output-stage swing, load, device topology, internal gain distribution, battery condition에 의해 제한된다. 따라서 “18V = 항상 +6.02 dB usable headroom”은 일반 법칙이 아니다.

A07 Core Position
Supply voltage is selected from required signal swing and engineering margin, not from product tier. 18V is not a tone grade; it is one possible way to enlarge the operating envelope of a circuit that is actually voltage-limited at 9V.

2. 정의 — Headroom, Dynamic Range, Noise, Output Level을 분리한다

Operational definition

A07 caution

Headroom

현재 nominal/peak signal과 정의된 clipping/distortion limit 사이의 여유.

“최대 출력”이나 “dynamic range”와 동일하지 않다.

Maximum clean output

제조사가 공개하지 않으면 supply voltage만으로 확정 불가.

Clipping threshold

파형 포화 또는 THD+N 기준으로 정한 비선형 시작점.

C04에서는 criterion을 사전에 고정해야 한다.

Noise floor

지정 bandwidth에서 측정한 출력 잡음.

18V라고 자동으로 낮아지지 않는다.

Dynamic range

최대 허용/clean signal과 noise floor 사이의 범위.

headroom 증가가 그대로 DR 증가가 되려면 noise floor가 같은 조건이어야 한다.

Nominal output level

정상 연주·flat setting에서 의도된 평균 출력.

18V로 바꿔도 gain이 같으면 자동으로 2배가 되지 않는다.

3. 회로 이론 — 9V→18V가 +6.02 dB와 일치하는 조건

단일전원(single-supply) 회로가 mid-rail 부근에 바이어스되고 양·음 방향의 여유가 대칭적이라고 가정하면, 이상적 peak swing은 supply에 비례한다. 같은 topology, 같은 gain, 같은 load, 같은 clipping criterion 아래에서 9V의 usable peak swing이 정확히 절반이고 18V에서는 rail margin이 그대로 비례 확대될 때 +6.02 dB에 접근한다.

실제 회로에서는 input common-mode range와 output swing이 rail과 독립적으로 제한될 수 있고, load current가 커지면 rail-to-rail stage도 rail까지 깨끗하게 도달하지 못한다. bias point가 정확한 중간값이 아니거나 positive/negative headroom이 비대칭이면 한쪽이 먼저 clip한다. regulated rail, charge pump, DC/DC converter가 있다면 battery voltage와 실제 analog rail도 동일하지 않을 수 있다.

Figure 1. 9V와 18V의 이상화된 rail/headroom 비교. 전압 2배는 이상 조건에서 +6.02 dB의 ceiling 차이를 만들 수 있지만, 실제 usable swing은 bias, device swing, load와 topology에 의해 제한된다. 개념도이며 제품 실측값이 아니다.

3.1 EQ boost와 internal-node clipping

+12 dB는 약 3.98×, +15 dB는 약 5.62×, +16 dB는 약 6.31×, +18 dB는 약 7.94×의 voltage ratio에 해당한다. 이 값은 “항상 출력이 그만큼 커진다”는 뜻이 아니라, 해당 대역에 그만큼의 boost를 요구할 수 있다는 뜻이다. pickup/source peak에 input gain, mixing gain, filter resonance 또는 EQ boost가 누적되면 최종 output jack 이전의 내부 노드가 먼저 포화할 수 있다.

따라서 A07의 분석 단위는 pickup output 하나가 아니라 Source peak → input boundary → input gain → per-source/filter processing → mixing → EQ/filter peak gain → inter-stage level → output gain → load의 전체 chain이다.

Figure 2. EQ/filter boost를 voltage ratio로 환산한 headroom-budget 보조 그래프. +12 dB는 약 3.98×, +18 dB는 약 7.94×이며, 실제 internal-node peak는 source level과 앞선 stage gain을 함께 고려해야 한다.

5. Candidate-by-candidate evidence audit

5.1 Lusithand Double NFP MKII

공식 제품 페이지는 Operation 9 to 27 volts, current draw 약 2.9 mA, 각 pickup별 resonant peak filter와 +3 dB standard / +6 dB switched Q boost를 공개한다. 넓은 supply range는 확인되지만 “18V에서 몇 dB headroom 증가”라는 제조사 정량 설명은 없다. 따라서 Configurator는 9V만을 강제하기보다 supported supply를 별도 기록하고, 실제 9/18V effect size는 C04에서 측정해야 한다.

5.2 Fishman Fluence Bass 2-Band EQ

Fishman은 독립 제품으로 Fluence Bass 2-Band EQ를 판매하며, 2026 OEM catalog는 Fluence Bass system의 battery를 9–18V로 표기하고 2-Band EQ current draw를 1.1 mA로 제시한다. 이 근거는 “Fluence Bass system-level supply”에는 강하지만, standalone EQ module만을 별도 18V-upgrade 대상으로 설명한 것은 아니다. 따라서 현재 Configurator의 “9V standard supply”는 표준 구현으로 유지할 수 있으나 “9V only”라고 단정해서는 안 된다.

5.3 Underhill Cali Dub

공식 페이지는 두 pickup용 BP buffers, 두 개의 FV variable-Q filters, EPB parametric bass EQ, active blend/volume을 공개한다. filter Q는 0–13 dB, filter frequency 130–5300 Hz, bass EQ ±7.5 dB와 30–200 Hz sweep, idle current 2.4 mA가 확인된다. 공개 페이지에서 supply voltage를 확인하지 못했으므로 9V/18V 규칙은 Unknown으로 남겨야 한다.

5.4 Glockenklang 3-Band

공식 electronics page는 gain 1 (0 dB), input 1.5 MΩ, Bass ±14 dB @40 Hz, Mid ±9 dB @550 Hz, Treble ±18 dB @18 kHz, power 9/18V / 2.3 mA를 명시한다. 18V 지원은 명확하지만 “18V가 권장” 또는 “18V가 몇 dB headroom을 추가한다”는 설명은 확인되지 않는다. 따라서 Configurator의 고정 18V는 사용 가능한 house configuration이지만 manufacturer requirement로 표현해서는 안 된다.

5.5 ZUTA Bass Core

공식 페이지는 1 MΩ input, 1 kΩ output, recommended load ≥10 kΩ, nominal input level up to +20 dBu, Bass ±16 / Mid ±15 / Treble ±12 dB, 9–18V supply와 약 500 h battery-life claim을 공개한다. “high headroom”과 low distortion/noise는 manufacturer claim이며, 9V와 18V 사이의 정량 delta는 공개하지 않는다. A07에서는 +20 dBu와 boost range를 중요한 published boundary로 기록하되, 18V의 실제 margin 증가는 C04로 넘긴다.

5.6 Noll TCM-4XM

Noll은 가장 유용한 정량 사례 중 하나다. Input >1 MΩ, output <10 kΩ, max input sensitivity 450 mV @9V, max output 4.5V @9V, S/N 96 dB, ±15 dB 4-band, 9V base / +18V optional, 1.5 mA @9V를 공개한다. 또한 추가 9V battery(18V)가 “more headroom and longer battery life”를 제공한다고 직접 설명한다. 다만 18V에서 max output이 정확히 2배라는 값은 공개되지 않았으므로 +6.02 dB를 자동 적용하지 않는다.

5.7 Darkglass Tone Capsule

Darkglass는 input 500 kΩ, output 1 kΩ, current ≈2.4 mA, Bass/Mid/HiMid ±12 dB, 9V–18V operation을 공식 공개한다. 그러나 official product page는 18V를 mandatory high-headroom mode로 정량화하지 않는다. Configurator의 18V default는 engineering choice로 둘 수 있지만 “manufacturer high-headroom requirement”라고 표기하면 근거를 넘어선다.

5.8 LHZ-05 / HAZ-style 3-Band

LHZ-05는 LHZ-04의 HAZ-style 2-band circuit과 MID-03을 통합한 현재 3-band 제품이다. 제조사의 BAT-01 설명은 9V와 18V 모두 정상 동작하며 선택은 personal preference라고 명시한다. 또한 9V에서는 aggressive playing과 boosted EQ에서 peak compression 및 high-frequency harmonic overtones가 나타나고, 18V에서는 peak compression이 줄어들며 nonlinear zone의 ceiling/headroom이 올라간다고 직접 설명한다. 따라서 Configurator의 9V “Classic HAZ Response” / 18V “High Headroom” 구분은 이번 후보 중 가장 직접적인 제조사 근거를 갖는다. 단, 이 설명은 현대 LHZ 구현의 manufacturer characterization이며 모든 HAZ-style clone에 일반화하지 않는다.

5.9 John East UNI-PRE 5

공식 manual은 active/passive 경로를 완전히 분리하고 pickup별 Class-A FET input stage와 0–12 dB gain trim, Bass ±18 dB, Mid ±14 dB, Treble ±18 dB를 제공함을 확인한다. 이 정도 boost/trim은 headroom budget에서 중요하지만, 현재 수집된 evidence set만으로 9V/18V delta를 정량화하지 않는다. UNI-PRE의 핵심은 voltage label보다 per-pickup gain calibration과 내부 processing headroom을 함께 관리하는 것이다.

5.10 ACG EQ-01

ACG 공식 자료는 EQ-01이 pickup별 variable low-pass filter와 overshoot peak level, global high-pass filter 또는 passive-tone variant를 갖는 filter-style preamp임을 확인한다. conventional 3-band ±dB EQ와 달리 filter cutoff와 resonance peak가 internal spectral peak를 만든다. supply, current, maximum swing이 현재 공개 evidence에서 확정되지 않으므로 A07에서는 filter state별 worst-case peak를 specification requirement로 정의하고 정량 결과는 C04로 넘긴다.

5.11 Nova Dual Filter Custom

공개된 제품 datasheet가 없는 RavenForge/custom 후보는 “Custom / specification required”가 정답이다. 최소 요구 사양은 supply range, current, Zin/Zout, filter cutoff range, maximum resonance/Q boost, input/output clean swing, noise floor, bypass/reference state다. 이 값이 정해지기 전에는 9V 또는 18V를 default로 고정하지 않는다.

7. 9V vs. 18V — Headroom / Dynamic Range / Noise / Runtime

7.1 Headroom

회로가 실제로 rail-limited 상태에 접근한다면 18V는 clean swing을 확장할 수 있다. 그러나 9V에서 이미 충분한 margin이 있으면 청감 변화가 없을 수 있다. 제조사별 지원 전압 자체보다 “9V에서 worst-case internal node가 limit에 얼마나 가까운가”가 더 중요한 판단 기준이다.

7.2 Dynamic range

Dynamic range는 maximum clean signal과 noise floor의 차이다. 공급 전압 상승으로 maximum clean signal이 커져도 noise floor가 동시에 변하면 증가량은 정확히 6 dB가 아니다. 따라서 18V의 DR 효과는 headroom과 별도 측정한다.

7.3 Noise

18V가 noise floor를 자동으로 낮춘다는 일반 규칙은 없다. 일부 회로는 higher rail에서 device operating point가 달라질 수 있고, battery/source impedance와 decoupling도 noise에 영향을 준다. 제조사가 공개한 “low noise”는 마케팅/사양 claim으로 기록하고 동일 bandwidth의 bench measurement와 구분한다.

7.4 Battery runtime

두 개의 동일 9V battery를 series로 연결하면 nominal voltage는 합산되지만 Ah capacity는 한 battery 수준으로 유지된다. stored energy(Wh)는 증가하지만 runtime은 회로의 supply-dependent current, battery chemistry, internal resistance, discharge curve, cutoff condition에 좌우된다. EMG BQC의 600 µA @9V / 740 µA @18V처럼 current가 두 배가 아닌 실제 사례가 있으므로 “18V = battery life 절반”은 성립하지 않는다.

“18V는 9V보다 무조건 소리가 좋다.”

False

9V에서 clipping/nonlinearity가 문제일 때 개선될 수 있지만, voltage 자체가 tone grade는 아니다.

“18V면 항상 정확히 +6.02 dB usable headroom이다.”

False / Conditional

ideal voltage ratio는 +6.02 dB지만 actual device swing, bias, load가 다르면 usable margin은 달라진다.

“18V면 dynamic range도 항상 +6 dB다.”

False

noise floor가 동일하다는 조건이 추가로 필요하다.

“18V면 output level이 자동으로 두 배다.”

False

nominal gain이 같으면 nominal output은 변하지 않는다. 최대 clean swing ceiling이 바뀔 수 있을 뿐이다.

“18V면 noise floor가 낮아진다.”

Unsupported as universal claim

noise는 topology, device, bias, grounding, bandwidth에 좌우된다.

“18V면 frequency response가 달라진다.”

Unsupported as universal claim

small-signal linear region에서는 동일할 수 있다. large-signal distortion/compression은 달라질 수 있다.

“pickup output이 작으니 onboard preamp clipping은 무시해도 된다.”

False

input gain + summing + EQ/filter peak로 internal node가 먼저 clip할 수 있다.

“18V면 battery life가 정확히 절반이다.”

False

series battery의 Ah와 circuit current가 단순 2× 관계가 아니다.

“rail-to-rail op amp면 rail까지 완전히 clean하게 swing한다.”

False

load와 output-stage 조건에 따라 rail margin과 distortion이 남는다.

12. RavenForge model application — 결과가 아니라 검증 요구사항

ASKR

active-source + onboard EQ 조합에서는 source 자체의 nominal/peak output과 EQ maximum boost가 함께 worst-case node를 만든다. 18V 지원 여부를 “프리미엄 사양”으로 보지 않고, complete chain의 published source level과 onboard EQ clean-swing spec을 대조한 뒤 부족한 정보는 C04에서 측정한다.

EMBLA

passive pickup + selectable preamp 조합에서는 input loading과 gain trim을 먼저 정의하고, blend 이후 boost에서 internal peak가 얼마나 커지는지 기록한다. 3-pickup option이 사용되면 summing condition과 simultaneous-source peak도 headroom map에 포함한다.

EDDA

filter-centric architecture에서는 conventional 3-band “최대 boost” 숫자만으로 위험 node를 찾기 어렵다. pickup별 low-pass cutoff, resonance/overshoot peak, blend ratio, global high-pass/treble state를 조합해 worst-case state를 정의한 뒤 clean-swing을 측정한다.

14. 통합 결론 — 전압은 tone label이 아니라 margin parameter다

이번 재연구에서 확인된 가장 중요한 사실은 “18V 지원”이라는 한 줄의 사양이 제품마다 전혀 다른 의미를 가진다는 점이다. Noll은 18V를 추가 headroom과 battery life의 수단으로 직접 설명하고, LHZ는 9V와 18V에서 의도적으로 다른 large-signal behavior를 설명한다. Darkglass와 Glockenklang은 9/18V compatibility를 공개하지만 18V의 효과를 정량화하지 않는다. Fishman Fluence Bass system은 9–18V 범위에서 운용되는 통합 시스템으로 문서화되어 있어 standalone EQ를 단순 “9V only”로 축약하면 정확하지 않다.

따라서 RavenForge의 supply policy는 “active면 9V”, “고급형이면 18V” 같은 전역 규칙이 아니라 product-specific supported range + RavenForge default + documented reason의 3요소로 바뀌어야 한다. 18V default를 선택할 수는 있지만, 그것이 manufacturer requirement인지 RavenForge의 engineering margin choice인지를 표시해야 한다.

RavenForge A07 design rule
Choose the supply from the worst-case required signal swing plus engineering margin. Document the reason. Do not infer tonal superiority from voltage, and do not infer exact usable headroom from battery voltage alone.
