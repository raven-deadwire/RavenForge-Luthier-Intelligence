A01 — From Mechanical Vibration to Electrical Signal

From string–structure coupling to magnetic transduction and electrical output

문서 목적
전기 기타와 베이스의 출력 신호를 개별 부품의 “톤” 합으로 설명하지 않고, 연주자의 가진에서 현–구조 결합, 픽업 위치의 spatial sampling, 자기회로의 flux modulation, coil 및 외부 부하의 electrical response로 이어지는 하나의 coupled signal system으로 정의한다. 이번 회차는 특정 pickup 위치나 pot 값의 정답을 확정하는 문서가 아니라, A02–A05와 C01–C02에서 각 변수를 분리·검증하기 위한 RavenForge 공통 reference model을 구축한다.

1. 연구 질문 — 전기악기의 신호는 어디에서 시작되고 어디에서 바뀌는가

전기 기타와 베이스의 최종 출력은 어느 한 부품이 독립적으로 생성한 결과가 아니다. 연주자가 현에 초기 변위와 속도를 부여하면 현은 장력·길이·선밀도·강성의 조건 아래 진동하고, nut/fret 및 bridge에서 neck/body 구조와 에너지를 교환한다. 그 결과 만들어진 현 운동 중 픽업이 위치한 공간의 성분이 magnetic circuit을 변화시키고, coil에 유도전압이 발생한다. 이후 pickup impedance와 control/cable/input loading이 다시 frequency response를 바꾼다 [1–7].

핵심 관점
Material does not travel into the pickup. 재료와 구조는 string dynamics의 boundary condition과 mechanical admittance를 바꾸며, pickup은 그 결과로 달라진 string motion을 읽는다.

Figure 1. A01에서 정의하는 RavenForge signal chain.

RavenForge schematic · literature framework based on Fletcher & Rossing, Paté et al., Horton & Moore, Paiva et al. [1–6].

따라서 기존의 `material → vibration → pickup → output`은 내부 shorthand로 유지할 수 있지만, 실제 설계·측정 문서에서는 `excitation → coupled string/structure dynamics → pickup-coordinate sampling → magnetic transduction → pickup impedance → electrical loading → output`으로 확장한다.

2. String — 이상적인 정상파에서 실제 악기 현으로

2.1 Ideal stretched string — scale, tension, linear density

이상적인 유연한 현에서 횡진동의 파동속도는 c = √(T/μ)이고, speaking length가 L일 때 고유주파수는 fₙ = (n/2L)√(T/μ)로 표현된다. 여기서 T는 tension, μ는 linear mass density, n은 mode number다 [1]. 이 식은 동일한 pitch 조건에서 scale length·string mass·tension이 어떻게 연결되는지 보여주는 RavenForge의 mechanical baseline이다.

이상적인 mode shape는 sin(nπx/L)로 나타낼 수 있으며 각 partial마다 node와 antinode의 위치가 달라진다. 따라서 현의 “전체 소리”는 공간 어디에서나 동일하지 않다.

Figure 2. 이상적인 string mode와 pickup spatial sampling의 기본 개념.

Idealized point-sampling schematic. 실제 pickup은 finite sensing width와 nonuniform magnetic field를 가진다 [1,5,6].

2.2 Real string — stiffness, damping, termination

실제 steel guitar/bass string은 ideal flexible string이 아니다. bending stiffness, core/wrap construction, 내부·공기 감쇠, fret/nut/bridge termination, 구조물과의 coupling 때문에 partial frequency와 decay가 이상모델에서 벗어날 수 있다. 특히 stiffness는 partial을 정확한 정수배에서 벗어나게 하는 inharmonicity를 만든다 [1].

Design rule
RavenForge에서 string response를 단일 “sustain” 값으로만 기록하지 않는다. 기본적으로 fundamental / harmonic amplitude / partial-specific decay를 분리해 기록한다.

3. String–Structure Coupling — boundary condition이면서 energy sink

현의 양 끝은 이상적인 fixed point가 아니다. bridge와 nut/fret를 통해 neck·body·hardware가 움직일 수 있고, 특정 주파수에서 구조의 mobility가 높으면 현의 에너지가 구조로 더 강하게 전달된다. driving-point mechanical admittance는 Y(ω)=V(ω)/F(ω)로 표현할 수 있으며, conductance Re{Y}는 구조로 전달·소산되는 에너지와 연결된다 [2,3].

Paté, Le Carrou & Fabre는 solid-body electric guitar의 decay를 isolated-string damping과 neck coupling을 결합해 예측했고, Fleischer는 dead spot에서 neck conductance가 높은 주파수와 짧은 string decay의 관계를 측정했다 [2,3]. 이것은 “목재가 pickup으로 직접 들어간다”는 설명보다 `material + geometry + joint + hardware → structural admittance → string modal amplitude/decay`라는 경로가 더 방어 가능함을 보여준다.

Design rule
수종명에서 tone을 직접 예측하지 않는다. assembly의 modal frequency, damping, FRF/admittance와 실제 string partial decay를 측정한다.

4. Pickup Position — tone adjective가 아니라 spatial sampling coordinate

자기 픽업은 air pressure나 body vibration을 직접 측정하는 마이크가 아니다. magnetic field 안에서 움직이는 ferromagnetic string의 운동을 감지한다. 이상적인 point sensor라면 n번째 mode의 위치계수는 Hpos(n,xp) ∝ sin(nπxp/L)로 생각할 수 있다 [5,6]. 따라서 특정 harmonic node 부근에 pickup이 놓이면 그 성분은 상대적으로 억제될 수 있다.

이 관점에서 “bridge pickup은 밝다”는 표현은 결과를 묘사하는 shorthand일 뿐 설계변수 자체가 아니다. bridge 쪽으로 이동하면 fundamental과 저차 partial의 displacement가 상대적으로 작아지는 조건이 생기고 upper-partial ratio가 달라질 수 있다. 실제 연구에서도 pickup position과 plucking point가 spectrum에 강한 signature를 남긴다 [5,6].

A01 scope
이번 회차에서는 pickup position이 spatial-sampling variable이라는 사실까지만 확정한다. mm별 coordinate, fret 변화에 따른 normalized x/L, harmonic null map과 finite sensing width 계산은 A02와 C01로 넘긴다.

5. Magnetic Pickup — mechanical domain에서 electrical domain으로

자기 픽업은 A01 signal chain에서 electromechanical transducer다. Faraday relation은 e(t) = −N·dΦ/dt로 쓸 수 있지만, 실제 기타 pickup을 단순한 “금속 현이 코일 옆에서 움직여 전기를 만든다”는 수준으로 축소하면 자기회로의 구조를 놓친다. permanent magnet, pole/blade, ferromagnetic string과 coil이 하나의 magnetic system을 이루며, 현 위치 변화가 coil-linked flux를 변화시킨다 [4,7].

Horton & Moore는 pickup response의 위치 의존성과 비선형성을 모델링했고, Lemarquand & Lemarquand는 permanent-magnet pickup의 magnetic circuit을 계산 대상으로 다뤘다 [4,7]. 충분히 강하고 가까운 magnet은 string motion에 back-action을 가할 수 있으므로 pickup을 완전히 비침습적 센서로 간주하지 않는다.

Design rule
Magnetic transduction은 pickup coordinate와 다른 문제이며, electrical filtering과도 다른 문제다. RavenForge 측정에서는 string–magnet gap과 magnet/pole geometry를 별도 변수로 기록한다.

6. Electrical Boundary — 유도전압 이후에는 impedance 문제다

유도 EMF가 생성된 뒤에는 pickup coil의 resistance, inductance, winding/self capacitance가 electrical transfer function을 형성하고, 여기에 pot·tone network·cable capacitance·amp/buffer input impedance가 결합한다. 따라서 pickup output은 “Faraday voltage” 그대로가 아니다 [5,8].

최근 controlled winding study에서는 같은 기본 magnetic architecture 안에서 turns와 wire gauge를 변화시키자 self-resonant frequency와 impedance peak가 함께 변했다 [8]. 즉 DCR 하나로 pickup의 brightness, output, resonance를 대체해서는 안 된다.

A01 boundary
R/L/C와 resonance/Q의 상세는 A03, pot/cable loading은 A04, buffer/input impedance는 A05에서 분리한다. A01은 mechanical → electromagnetic → electrical domain의 경계를 정의하는 데 집중한다.

8. RavenForge Application — ASKR, EMBLA, future 3PU

8.1 ASKR — bridge-near pickup을 target response로 다시 정의한다

ASKR의 공격적인 성격은 “pickup을 최대한 bridge 쪽에 둔다”는 관습으로 끝내지 않는다. A02/C01에서 fundamental suppression, upper-partial ratio, harmonic null avoidance와 attack spectrum을 target으로 정의한 뒤 coordinate를 역산한다. 즉 `concept → target response → pickup coordinate`가 된다.

8.2 EMBLA — passive / buffered architecture를 loading 문제로 본다

EMBLA에서 passive/active의 차이는 단순한 preamp 유무가 아니다. passive high-impedance pickup은 cable/load interaction이 voicing의 일부가 될 수 있고, pickup 직후 high-Z buffer를 두면 downstream cable의 영향을 크게 분리할 수 있다. 따라서 C02/A05에서 “남길 loading character”와 “제거할 variability”를 구분한다.

8.3 Future 3PU — 세 pickup을 서로 다른 spectral sampler로 설계한다

향후 3PU layout은 neck/middle/bridge라는 관습적 명칭보다 normalized coordinate, harmonic-null overlap, spectral complementarity를 기준으로 배치한다. 동일 string의 서로 다른 공간 샘플러라는 관점이 multi-pickup architecture의 출발점이다.

11. 현재 결론 — 악기는 coupled signal system이다

A01의 목적은 새로운 “톤의 서열”을 만드는 것이 아니다. 전기 현악기의 출력은 player excitation, coupled string/structure dynamics, spatial sampling, magnetic transduction, pickup impedance와 external loading이 연속적으로 결합한 결과다. 따라서 material, pickup position, magnet, winding, pot과 cable을 같은 종류의 tone variable로 한 표에 섞지 않는다. 각 요소는 서로 다른 causal position과 측정법을 가진다.

Current design position
The string is the mechanical carrier. The pickup is the electromechanical boundary. The circuit is the electrical filter. The instrument is the coupled system.

RavenForge의 기존 shorthand `material → vibration → pickup → output`은 앞으로 실제 연구 문서에서 `excitation → coupled string/structure dynamics → pickup-coordinate sampling → magnetic transduction → pickup impedance → electrical loading → output`으로 확장한다.
