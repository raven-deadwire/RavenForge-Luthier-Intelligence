C01 — Pickup Position FFT Mapping

Validating pickup-position spatial sampling with repeatable spectral measurement and an explicit uncertainty budget

DATE2026-09-12
CATEGORYSignal & Transduction / Measurement
STATUSVerified protocol foundation

1. Research purpose

C01 converts the pickup-position spatial-sampling model developed in A02 into a measurement problem. The purpose is not to declare a particular pickup position “better,” but to test whether the modal weighting predicted by the normalized coordinate r = d / Lappears as a repeatable signature in the measured output spectrum.

System boundary: Hpos(n)=sin(nπd/L)is an ideal-string geometric spatial factor, not the complete pickup output. Real measurements also contain pluck excitation, finite sensing aperture, magnetic transduction, string non-idealities, electrical loading, and analysis-window effects.

2. Verified physical and mathematical model

2.1 Point-sensor position factor

For an ideal string fixed at both ends, the nth mode can be written as sin(nπx/L). A point sensor at d therefore has a spatial weighting proportional to sin(nπd/L), with ideal node condition d/L=m/n. A real magnetic pickup, however, senses a finite magnetic region, so a theoretical node does not guarantee exactly zero measured voltage.

2.2 Fretted notes

Under ideal equal temperament, speaking length at fret F is LF=L0·2−F/12. A fixed pickup therefore moves to rF=(d/L0)·2F/12 in normalized coordinates. Real tests must record saddle compensation and the fret-crown witness point for each string.

2.3 Pluck point versus pickup point

The modal coefficients of an ideal triangular initial displacement contain the pluck coordinate q. With a first-order velocity-sensitive magnetic-pickup approximation, the harmonic amplitude can contain a product of the pluck-position and pickup-position terms.

Cₙ ∝ sin(nπq/L) / [n²(q/L)(1−q/L)]Vₙ ∝ sin(nπq/L) · sin(nπd/L) / n

Consequently, uncontrolled pluck position confounds the pickup-position experiment. C01 therefore requires controlled excitation geometry.

2.4 Finite sensing aperture

A real pickup is not a point sensor. Using a sensitivity kernel g(u), the spatial response can be generalized as

Hg(n)=∫g(u) sin[nπ(ξp+u/L)]du

For an ideal symmetric rectangular aperture this produces a sinc-like attenuation multiplying the central sine term. Finite width therefore averages high-order modes, but a symmetric kernel does not by itself shift the ideal center node. Physical bobbin, cover, pole or blade width must not be assumed to equal the effective magnetic sensing width.

The recommended analysis detects onset, applies a consistent post-onset window, estimates f₀, and tracks actual modal peaks. Low bass strings require enough record duration to separate low-order partials; the trade-off between time localization and frequency resolution must be documented.

4. C01 bench protocol

Geometry capture→String / tuning stabilization→Pickup gap→Repeatable pluck→Specified electrical load→Recording→Modal tracking→Predicted vs measured

C01-A — Position-signature validation: where practical, move the same pickup between positions instead of comparing different neck and bridge pickups. This reduces the risk of mistaking coil, magnet or electrical differences for a position effect.

C01-B — Fret-dependent mapping: measure the same pickup on open and fretted conditions to test whether the spatial signature migrates with rF.

  • Strings: record brand/model/gauge/age, tuning, speaking length, action and witness points.
  • Pluck: control coordinate, direction, plectrum material/thickness and release condition.
  • Pickup: record the sensing-center proxy and string gap per string.
  • Electrical: hold the A04 load boundary constant; loading is a control variable in C01.
  • Recording: document gain, ADC/interface, sample rate, bit depth and channel polarity.
  • Archive raw WAV, geometry table, gain/calibration metadata, analysis-script version, window/FFT settings and extracted modal/complex data.

5. Multiscale and slanted pickups

On a multiscale design such as ASKR, pickup position cannot be represented by a single millimetre value. Each string requires

rᵢ = dᵢ / Lᵢ

and should be logged as a per-string trajectory. Pickup slant does not automatically “correct” multiscale geometry: it changes dᵢ, while the intended spatial weighting depends on the actual dᵢ/Lᵢ distribution and must be measured.

6. Boundary for multiple pickups

With two pickups active, signed spatial factors combine with each pickup's magnetic/electrical transfer and the loading interactions studied in A04. The primary C01 protocol should therefore remain a single-pickup characterization. Multi-pickup series/parallel/polarity tests belong to an extension. Magnitude spectra also discard sign, making phase increasingly important for pickup combinations.

7. Uncertainty and repeatability

C01 does not impose an arbitrary fixed “three repeats” rule or an unsupported ±1 dB acceptance band. A pilot study should estimate within-condition variance, after which repeat count can be chosen from the required confidence interval or statistical precision. The uncertainty budget should include geometry, pluck coordinate, pickup gap, excitation repeatability, spectral estimator, and between-day drift.

Predicted-versus-measured evaluation should not rely on correlation alone. Useful descriptors include attenuation near predicted nodes, node-location error, harmonic-ratio residuals, weighted RMSE and confidence intervals. The first C01 campaign is best treated as model validation / parameter estimation rather than a binary pass/fail test.

9. RavenForge design rule

Current design position: pickup placement is recorded as per-string dᵢ/Lᵢ and as a measurable modal-weighting problem rather than as “bridge/neck” tone adjectives. No coordinate is declared optimal before C01 measurement.
