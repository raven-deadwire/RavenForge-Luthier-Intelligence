C01 — Pickup Position FFT Mapping

픽업 위치의 공간 샘플링 가설을 반복 가능한 스펙트럼 측정과 불확도 분석으로 검증하는 방법

DATE2026-09-12
CATEGORYSignal & Transduction / Measurement
STATUSVerified protocol foundation

1. 연구 목적

A02에서 정의한 pickup-position spatial sampling을 실제 측정 문제로 전환한다. 이 회차의 목적은 특정 pickup position이 “좋다/나쁘다”를 판정하는 것이 아니라, 정규화된 위치 r = d / L가 예측하는 modal weighting이 실제 출력 스펙트럼에서 반복 가능한 signature로 나타나는지 검증하는 것이다.

핵심 경계: Hpos(n)=sin(nπd/L)는 이상적 현의 geometric spatial factor이며, 실제 pickup output 전체가 아니다. 실제 측정에는 pluck excitation, finite sensing aperture, magnetic transduction, string non-ideality, electrical loading, analysis window가 함께 개입한다.

2. 검증된 물리·수학 모델

2.1 Point-sensor 위치계수

양 끝 고정 이상현의 n번째 mode shape를 sin(nπx/L)로 둘 때, 위치 d의 점 센서는 sin(nπd/L)에 비례하는 공간 weighting을 갖는다. 이상적 node condition은 d/L=m/n이다. 그러나 실제 magnetic pickup은 공간적으로 유한한 자기장을 사용하므로 실제 null이 반드시 0 V가 되는 것은 아니다.

Bridge / witness point→ d →Effective sensing coordinate→Speaking length L

Figure 1. C01 geometry boundary. Slanted or multiscale instruments require per-string dᵢ and Lᵢ.

2.2 Fretted note

이상적 equal temperament에서 F fret의 speaking length는 LF=L0·2−F/12이고, 고정 pickup의 정규화 좌표는 rF=(d/L0)·2F/12로 증가한다. 실제 실험에서는 saddle compensation과 fret crown의 witness point를 현별로 기록해야 한다.

2.3 Pluck point와 pickup point

이상적인 triangular initial displacement의 modal coefficient에는 pluck coordinate q가 들어간다. magnetic pickup을 1차적으로 velocity-sensitive transducer로 근사하면 harmonic amplitude의 공간구조는 pluck term과 pickup term의 곱으로 나타날 수 있다.

Cₙ ∝ sin(nπq/L) / [n²(q/L)(1−q/L)]Vₙ ∝ sin(nπq/L) · sin(nπd/L) / n

따라서 pickup position을 시험하면서 pluck position이 흔들리면 두 요인이 섞인다. C01은 excitation fixture를 통제해야 한다.

2.4 Finite sensing aperture

실제 pickup은 point sensor가 아니므로 sensitivity kernel g(u)를 사용해

Hg(n)=∫g(u) sin[nπ(ξp+u/L)]du

로 표현하는 것이 더 일반적이다. 대칭 rectangular aperture의 이상적 경우에는 중앙의 sine term에 sinc형 attenuation이 곱해진다. 즉 finite width는 고차 mode를 평균화하지만, 대칭 kernel 자체가 center node를 자동으로 옮기는 것은 아니다. 또한 bobbin/cover/pole 폭을 effective magnetic sensing width와 동일시해서는 안 된다.

4. C01 bench protocol

Geometry capture→String / tuning stabilization→Pickup gap→Repeatable pluck→Specified electrical load→Recording→Modal tracking→Predicted vs measured

C01-A — Position signature validation: 가능하면 서로 다른 neck/bridge pickup을 비교하지 않고 동일 pickup을 위치만 이동시킨다. 그러면 coil/magnet/electrical differences가 position effect로 오인되는 것을 줄일 수 있다.

C01-B — Fret-dependent mapping: 동일 pickup에서 open / 여러 fret 조건을 측정하여 rF 변화에 따라 spatial weighting signature가 이동하는지 본다.

  • 현: brand/model/gauge/age, tuning, speaking length, action/witness point 기록
  • pluck: coordinate, direction, plectrum material/thickness, release condition 고정
  • pickup: 각 현별 sensing-center proxy와 string gap 기록
  • electrical: A04에서 정의한 load 변수를 고정. C01에서는 loading을 연구변수가 아닌 통제변수로 취급
  • recording: gain, ADC/interface, sample rate, bit depth, channel polarity를 기록
  • archive: raw WAV, geometry table, calibration/gain metadata, analysis script/version, window/FFT settings, extracted complex/modal data 보존

5. Multiscale 및 slanted pickup

ASKR 같은 multiscale에서는 “pickup position”을 한 개의 mm 값으로 쓰지 않는다. 각 현마다

rᵢ = dᵢ / Lᵢ

를 계산해 per-string trajectory로 기록해야 한다. pickup slant가 scale-length 차이를 자동 보정한다는 주장은 성립하지 않는다. slant는 각 현의 dᵢ를 바꿀 뿐이며, 목표한 spatial weighting을 만드는지는 실제 dᵢ/Lᵢ 분포와 측정으로 확인해야 한다.

6. Multiple pickups의 경계

두 pickup을 동시에 사용하면 signed spatial factor뿐 아니라 각 pickup의 magnetic/electrical transfer와 A04의 loading interaction이 함께 들어간다. 따라서 primary C01 protocol은 single-pickup characterization으로 제한하고, multi-pickup series/parallel/polarity 실험은 extension으로 분리한다. magnitude spectrum만으로는 sign/polarity 정보를 잃으므로 multi-pickup 연구에서는 phase가 더 중요하다.

7. 불확도와 반복성

고정된 “3회 반복”이나 임의의 ±1 dB 합격선을 문헌 근거 없이 채택하지 않는다. pilot run에서 within-condition variance를 추정한 뒤 필요한 반복수를 정하고, 최소한 geometry, pluck coordinate, pickup gap, excitation repeatability, spectral estimator, between-day drift를 uncertainty budget에 포함한다.

비교 지표는 단일 correlation보다 predicted null 부근 attenuation, null-location error, harmonic-ratio residual, weighted RMSE, confidence interval을 함께 보는 것이 적합하다. C01은 첫 단계에서 pass/fail 시험보다 model validation / parameter-estimation study에 가깝다.

9. RavenForge design rule

현재 설계 위치: pickup placement는 “bridge/neck tone adjective”가 아니라 현별 dᵢ/Lᵢ와 측정 가능한 modal weighting의 문제로 기록한다. 하지만 C01 실측 전에는 특정 좌표를 최적값으로 선언하지 않는다.
