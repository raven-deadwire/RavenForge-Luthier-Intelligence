RAVENFORGE

Signal & Transduction Research Log

A06 — Onboard Preamp Architecture

Designing gain · mixing · EQ · output after the pickup-facing boundary as a single low-Z signal system

Document purpose
Reframe the onboard preamp not as a simple active EQ or bass/mid/treble control module, but as the internal signal architecture that extends from a passive or active pickup source to the instrument output. Starting from the pickup-facing input boundary defined in A05, this log brings pickup isolation, mixing, gain structure, equalization, output drive, power, and bypass/reference state into one design language. Architectures are compared using published manufacturer specifications and circuit theory, while undisclosed internal topologies are not inferred and actual RavenForge prototype effect sizes are deferred to later experimental logs.

1. Research question — Where does an “active bass” actually become active?

Reducing instruments with onboard preamps to a simple passive/active binary hides important structural differences. A system may retain passive pickups and a passive volume/blend network and make only the EQ active; it may place a buffer immediately after the pickup to define source loading; or it may buffer each pickup independently before active mixing. Systems such as the John East UNI-PRE even maintain independent active and passive paths and provide a separate FET input stage and gain trim for each pickup [6].

A06 Core Position
An onboard preamp is not merely an EQ attached to an instrument. It is the architecture that decides where a directly coupled high-impedance pickup network ends and an actively controlled low-impedance signal system begins.

2. Architecture taxonomy — Classify by signal path, not by product name

The Type I–V scheme below is not an industry-standard taxonomy; it is a RavenForge working taxonomy for structural comparison. Its purpose is not to rank products, but to state explicitly which loading and pickup interactions are preserved and which interactions are isolated.

Figure 2. RavenForge working taxonomy. Even among instruments called “active basses,” the point at which the active domain begins and the mixing method can differ.

Passive PU → passive V/B → EQ/preamp → out

Only the downstream section is made active while retaining the existing pickup/pot interaction

II — Buffered source

Passive PU → buffer → controls/EQ → out

Maintains the passive reference and active path separately

The UNI-PRE is a representative example that combines characteristics of Type III and Type V. The manufacturer states that its active and passive volume/blend paths are completely independent, and that in the active path each pickup has its own input buffer/amplifier and 0–12 dB gain trim [6]. This allows pickups with different output levels to be level-matched within the active path.

3. Input boundary — Zin is not merely a compatibility number

From the A03–A05 perspective, a passive magnetic pickup is not a zero-impedance voltage source but a resonant source with frequency-dependent source impedance ZPU(f). The preamp input impedance Zin(f) is therefore not a transparent number that simply “accepts” the pickup; it is one of the boundary conditions that determines the damping of the loaded resonance [1,9].

The generalization “higher Zin = better sound” is inappropriate. A higher Zin generally reduces resistive damping of the pickup resonance, but if a pickup/network is intentionally voiced into a 250–500 kΩ load, moving it to a 1 MΩ buffer is itself a different tonal condition. A06 records Zin as a voicing parameter, not as a quality ranking.

4. Pickup mixing — A blend pot alone does not describe the topology

In a passive blend, each pickup’s source impedance and the blend/volume pots form one network, so the control position of one pickup can affect the load seen by the other pickup and the resulting mixed response. If each pickup is buffered independently before mixing, the mixer instead handles low-Z sources, greatly reducing mutual loading between the pickups themselves.

The UNI-PRE’s dual active/passive path description shows this distinction clearly at product level. The manufacturer explains that in active mode each pickup passes through an independent input buffer/amplifier, isolating the pickups from one another and enabling smooth blending and pickup level matching [6].

Specification rule
In RavenForge electronics documentation, do not record only a component value such as “Blend: MN250k.” First identify the topology as Passive interaction blend / Buffered blend / Active summing.

5. Gain structure — EQ boost and “preamp gain” are not the same thing

If gain is collapsed into a single number in an onboard system, it becomes difficult to trace where clipping occurs. For analysis, it is more useful to separate source level → input gain → mixing/summing → EQ gain → output stage. The Bartolini NTMB+FL provides an internal 0–12 dB gain trim separate from EQ boost/cut, while the UNI-PRE also provides 0–12 dB active gain trim for each pickup [4,6].

In a system that uses large EQ boosts, the available swing may be exceeded in a stage after the EQ even when the input stage itself is not clipping. A06 therefore specifies not only overall gain but stage-by-stage gain allocation, worst-case cumulative boost, and the point chosen as the reference level.

These differences do not mean that one frequency is “better” than another. Using a 2.8 kHz high-mid control instead of conventional treble, as in the Tone Capsule, changes the tonal operations available to the player. A sweepable mid or selectable center frequency expands the reachable state-space. An ideal EQ specification should therefore include not only center/corner frequency, but also shelf/peaking behavior, Q or slope, boost/cut range, and control law.

TI SLOA042 describes one implementation of a classic Baxandall-type active tone control in which the frequency-setting network is placed in the op-amp feedback loop [10]. The existence of that literature does not justify classifying every onboard preamp as Baxandall. Internal filter topology is not inferred for products without a manufacturer schematic or other reliable circuit documentation.

7. Active-flat ≠ Passive bypass — Separate the reference states

Putting the EQ controls at their center detents does not make the active signal path disappear. ZUTA claims that the Bass Core affects 20 Hz–20 kHz by no more than ±0.5 dB with all knobs neutral, yet it is still an active circuit with a 1 MΩ input and 1 kΩ output [7]. Even when the frequency magnitude is nearly flat, source loading, noise, maximum signal swing, output impedance, and downstream coupling already differ from the passive path.

8. Output boundary — The preamp redefines the instrument as a low-Z source

Published output impedances include 1 kΩ for the Tone Capsule, 1 kΩ for the ZUTA Bass Core, 2 kΩ for the EMG BQC, and 100 Ω for the Aguilar OBP-3 [2,3,5,7]. These low-Z outputs create a source condition that is less sensitive to downstream cable/load effects than a passive magnetic pickup directly coupled to a long cable capacitance.

However, saying that “cable effects disappear” is too strong. The cable remains a load that the output stage must drive, and actual closed-loop Zout and capacitive-load stability depend on frequency and circuit topology. A06 records output impedance and recommended minimum load as separate specifications. ZUTA recommends a load of at least 10 kΩ [7].

9. 9 V / 18 V — An operating condition, not a tone adjective

Using 18 V does not automatically “improve sound quality.” In a single-supply analog stage, supply voltage is one factor that sets the upper limit of possible signal swing, but actual usable swing is constrained by the device input common-mode range, output swing, bias point, load current, closed-loop gain, and distortion criterion.

Analog Devices AN-581 explains that biasing the output near midsupply is a common way to obtain the maximum bidirectional swing from a given single supply, and notes that a simple resistor-divider bias can create power-supply-rejection and stability problems [8]. EMG likewise recommends 18 V operation for the BQC under strong playing and bass/treble boost conditions [5].

A06 boundary
Reject both “18 V = better sound quality” and “18 V = exactly twice the usable headroom.” A06 records supply only as an architectural requirement; actual headroom and clipping effect sizes are left to A07 and the later C04 experiment.

10. Power · noise · bias — The battery is part of the signal architecture

In an onboard system, the battery and bias/reference network cannot be treated as conditions outside the instrument. The Tone Capsule publishes current consumption of about 2.4 mA, while the EMG BQC specifies 600 µA at 9 V and 740 µA at 18 V [2,5]. Low current draw benefits battery life, but low power does not automatically imply low noise, high headroom, or wide bandwidth.

The virtual reference and decoupling of a single-supply stage directly affect transfer and stability. AN-581 explains that if a midsupply divider is not adequately bypassed, supply variation can enter the signal path through the reference and degrade PSR, and that instability can occur under large output-current conditions [8]. Architecture documentation should therefore include reference topology, decoupling, current draw, and turn-on behavior as well as supply voltage.

14. Application to RavenForge models

The most important design principle from A06 is not to rank preamps simply by price. Treating different modules such as ZUTA, Noll, and John East only as “Standard → Upgrade → Premium” hides architectural differences. A system such as the UNI-PRE, with per-pickup buffering and independent active/passive paths, changes the topology by much more than merely replacing an EQ module.

In a design such as ASKR, where the source itself is an active pickup, the Zin problem cannot be applied in the same way as with a passive magnetic pickup. Conversely, if pickup interaction and passive filtering are deliberately part of the voice, as in EDDA, a buffer placed immediately after the pickup may remove the intended coupled behavior. In EMBLA as well, “preamp selection” becomes a boundary choice depending on the pickup and the placement of passive controls.

RavenForge design rule
Preamp selection = topology selection. Choose the signal-path structure to match the source architecture and intended player operation, rather than component price or the number of EQ bands.

16. Research boundary and subsequent logs

A06 establishes only the architecture and specification language. A07 — 9V vs. 18V: Headroom and Dynamic Range will treat supply voltage, rail margin, clipping, and signal level separately. B06 — Rethinking the Internal Signal Path will extend the stages and boundaries defined here into the actual internal control/routing architecture of the instrument.

C03 — Preamp Frequency Response Mapping will measure EQ curves, active-flat response, gain, and output response, while C04 — Headroom Test will validate 9/18 V maximum swing, THD+N, and clipping threshold. In accordance with the current master-schedule policy, the C-series experiments are deferred to a later phase.

17. Source status / interpretation boundary

Product values in this log prioritize manufacturer and official technical documentation. Terms such as “transparent,” “high headroom,” and “studio-quality” are treated as manufacturer claims, not as independently measured facts. ZUTA’s neutral ±0.5 dB and +20 dBu input-level figures are likewise manufacturer-published specifications [7].

The op-amp type, filter topology, Q, and internal gain distribution of products without published schematics are not inferred. This document is an architecture study based on literature, circuit theory, and published specifications; it does not contain RavenForge prototype measurements. Actual effect sizes and acceptance thresholds will be determined in later C-series work.

18. Current conclusion — The onboard preamp is a signal-domain architecture

Current conclusion
Onboard preamp architecture is the set of electrical boundaries and control stages that determines where a pickup network ceases to behave as a directly coupled high-impedance source and becomes an actively conditioned, mixed, filtered, and low-impedance output system.

The defining issue is not whether a preamp “has a 3-band EQ.” A06 asks where the source is isolated, how signals are mixed, at which stage gain is created, what tonal state-space is made available, and through what dynamic/output boundary the signal leaves the instrument. RavenForge will therefore document onboard electronics as signal architecture and a measurable specification bundle rather than as a component list.
