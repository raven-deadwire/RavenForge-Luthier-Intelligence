운영 데이터

RavenForge 공방 운영용 내부 페이지입니다. 사이트 메뉴와 검색에는 노출되지 않습니다.

공방 지역 외기 기록

기상청 지상관측(ASOS) 일자료와, 그 공기에서 목재가 도달하는 평형함수율(EMC) 추정치입니다. 실외 공기 기준이므로 공방 실내 측정(NB01 프로토콜의 습도계 기록)을 대신하지 않습니다.

악기 카테고리 검색 관심도

네이버 데이터랩 검색어 트렌드. 값은 상대 지수로, 이 요청에 포함된 모든 그룹 중 가장 높은 주가 100입니다. 그룹·검색어는 ops/config/search-trends.json에서 바꿉니다.

데이터는 GitHub Actions의 “Operations data” 워크플로가 갱신합니다(외기 매일, 검색 트렌드 매주 월요일).
